# 场馆排期与需求变更 AI 软件报价说明

编制日期：2026年10月24日。项目尚未开始研发，本文件为后续软件建设的立项预算建议，不能当作已签合同或已完成开发。所有工作量、单价、容量和工期均须在真实需求复核后确认；不重复计算此前已交付的调研报告、访谈演练和流程图。

## 软件范围

一期暂按单一组织、1个场馆、20个区域或共享资源、30个账号、10名同时在线用户、3种CSV或XLSX模板和1家授权模型服务商估算。这些数字是报价边界假设，不是用户已经确认的业务规模。

拟建设需求复核及原型、数据关联与只读导入、资源与排期工作台、确定性冲突规则、变更申请与版本差异、AI字段候选及来源引用、AI交接摘要、人工复核、权限审计、测试评测、部署试行、源码文档和培训。软件只在内部保存确认记录，不自动向既有系统写回占档或合同结果。自动锁档、签约、外发承诺及外部系统写权限不包含在一期授权中。

## 模型调用与资源假设

暂按10000次计费请求/月、每次6000输入token和1500输出token估算。火山方舟豆包1.8在“每次输入不超过32千token且输出超过0.2千token”的在线档位，输入与输出单价分别为0.8元及8元/百万token；本轮于2026年10月24日核查，仅作计价演示，实际按选定型号、档位及账单执行。[官方模型说明](https://docs.volcengine.com/docs/ark/bytedance-seed-1-8?lang=zh)

据此，模型月费示例为60百万输入×0.8＋15百万输出×8＝168元。另以应用及数据库1200元/月、备份存储日志300元/月作内部容量预留，合计1668元/月。云费用未取得供应商正式配置报价；模型请求数及token开销未实测，不等同于业务单量，需考虑实际重试、历史上下文、思考及工具往返。

模型调用费用只是运行成本的一部分，不代表AI功能开发费用。额外OCR、搜索工具、短信、商业许可证、专业安全测评、GPU、现场驻场及异地差旅不在默认预算中。

## 时间 保障与验收

建议约16周：第1至2周需求与方案，第3至10周核心及AI联调，第11至12周测试部署，第13至16周受控试运行与验收。资料、权限、样本和客户评审条件具备后排期；150人日不等于150个自然日。四周试运行不是四周完成全部软件研发。

验收前由双方确认需求、岗位、规则、字段、30条回放样本及AI效果评测方法。有限样本通过不代表生产环境100%准确。关键字段或版本不明时进人工队列；正式结论须由授权人员确认。验收后12个月约定功能的缺陷修复包含于建设费，新增需求和之后的可选年度运维另行约定。

# 详细项目设计方案
版本 1.0　编制日期 2026年11月6日

本方案描述当前 0.10.0 包结构及 11 月 4 日审批扩展，并对待建设模块单独提出设计边界。项目以服务端身份、规则和事务掌握执行权，模型仅提出受限工具调用。需求编号沿用第 06 册 R01 至 R10。

## 分层与部署
入口层为问答、Agent、草稿及管理员页面；FastAPI 提供 HTTP 与 SSE、登录、CSRF、所有权和错误信封；业务层由 RAG、LangGraph Harness、确定性工具及审批服务组成；数据层为业务 SQLite、LangGraph SQLite checkpoint、FAISS、本地制度及模型缓存。

当前仅监听 127.0.0.1，单 worker，同目录由 OS 实例锁保护。静态资源和模板随 wheel 打包，业务数据由绝对目录配置。企业 HTTPS、SSO、制度 ACL、多实例及正式占档都需要另行建设，不通过调整 worker 数声称支持。

## Agent 正常与变更时序
服务先验证身份和幂等编号，再在数据库原子消耗一次模型预算。新申请依次调用 search_policy、check_availability、validate_request，只有 PASS 可调用 create_draft。变更还必须 get_booking_context 读取本人原排期；修改候选后旧检查不可复用。

create_draft 读取服务端规范候选，保存完整预览与摘要并持久中断。页面完整接收后开放 H1，可信确认接口核对所有权、CSRF、摘要、期限及等待状态，再恢复 checkpoint。在写事务中复核当前权限、规则、资源和原版本，消费凭据并创建唯一草稿。模型文本不能确认，确认不增加模型轮次。

## 人工提交与审批状态机
draft 经 H2 本人提交进入 submitted；submitted 经 H3 获授权且非申请人的管理员处理为 approved 或 returned。returned 在内容仍适用且重校验满足时可再次提交。修改内容需要新建草稿，当前无原地编辑接口。

提交带 expected_version；通过还带最新详情的 review_hash，绑定草稿内容和复核依赖。状态变更与审批快照同事务保存；并发和陈旧页面返回冲突，不自动重试旧决定。approved 只代表审核通过，不插入资源占用、不切换原排期。

## 接口与错误协议
| 接口 | 输入或用途 | 控制 |
| --- | --- | --- |
| POST /chat | session_id及问题，SSE回答 | 本人会话、CSRF、幂等与来源 |
| POST /agent/runs | 新任务 | 账号、业务授权、预算 |
| Agent确认接口 | confirmation_id、preview_hash、决定 | 以 docs/Agent执行循环说明.md 的实际契约为准 |
| POST /api/drafts/{id}/submit | expected_version | 本人及当前业务复核 |
| POST /admin/api/approvals/{id}/decision | version、approve/return、comment、review_hash | 场馆审核权、禁止自审、当前版本 |
| GET /admin/api/approvals/summary | days为7或30 | 当前审核范围内全量只读汇总 |

响应信封为 code、message、request_id、data。开流前错误返回相应 HTTP，开流后用 SSE error，不能以200判成功。401重新登录，403核查授权，409刷新复核；网络和持久化失败先读实际状态，再决定是否使用原幂等编号重试。

## 知识库和模型边界
Embedding 默认本地 BAAI/bge-small-zh-v1.5，索引按制度与模型配置快照建立；运行时修改制度后需重启。生成模型由后端环境配置，Agent供应商还需支持 tools、tool_calls 和 tool_call_id。密钥不进前端与文档，正则脱敏不能代替企业数据治理。

## 待建设模块设计
R09 导入先验证约定模板和只读权限，保留原文件摘要、行号、发生时间与接收时间，将缺失与未确认分别标记。文档ACL须在检索前按当前身份过滤，索引更新以版本切换方式发布，失败保留旧快照并显示时间。

R10 摘要只读取已授权版本，输出候选字段、来源和未结项；不确定项进入人工队列。正式占档若未来获授权，应另设计容量与区间冲突的原子占用事务和旧新版本切换，不能复用当前 approved 状态作为占档成功依据。

## 测试与交付
设计模块通过第06册矩阵映射 T01 至 T10，离线回归以 tests/ 为准。上线前完成样本标注、权限负例、五轮边界、重启幂等、并发审批和停机恢复；交付 wheel、版本号、配置表、运行手册、验收证据及已知限制。历史72项结果只作已有记录，本轮文档不把它们当作新增业务验收结论。

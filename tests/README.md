## 实际验证与边界

- 选定的25项全部通过，每类5项；另完成全量离线回归83项，通过83项。这25项属于83项的子集，不能相加为108项不同测试。
- Agent、审批和权限使用真实JWT/CSRF、LangGraph、SQLite与业务校验；普通聊天夹具固定测试身份。模型和检索使用脚本替身，不代表真实模型准确率、Embedding效果、生产性能或上线验收。
- 图示取自本次执行的接口响应摘要及结果，数据库快照只读采集。图内状态为响应中观察到的状态集合，不表示同一对象的状态迁移；采样节点间箭头仅表示记录顺序。完整记录见执行证据，图示不是浏览器截图。
- 证据排除请求头、口令、Cookie、JWT、模型密钥、问题回答全文及制度原文；原始JUnit、数据库与临时预览留在仓库外。证据保留基线提交、工作区差异及源码SHA256，原有RAG本地改动未纳入本次提交。
- 用例耗时包含账号哈希、测试夹具与故障注入，不能当作生产响应时延。负例中的401、403、409、422可能正是预期结果。

## 复现

从项目根目录运行，输出目录必须位于仓库外且尚不存在。脚本拒绝覆盖旧证据；出现失败时保留原运行记录，修复后另建目录复验。

```powershell
python -m pip install -e '.[test]'
python tests/scenarios/run.py --output-dir "$env:TEMP\dhls-scenarios-new-run"
```

执行器按照 `cases.json` 选择25个不同参数化用例，输出 `results.json`、`junit.xml` 和隔离运行数据。成功标准为退出码0、25项均passed、每类5项；跳过与未执行不能算通过。它不自动覆盖本次归档Word，新的运行结果须另行审阅后发布。

全部回归入口为 `python -m pytest tests mvp/tests -q -p no:cacheprovider --basetemp <仓库外独立目录>`。各工程测试仍位于 `tests/api/`、`tests/core/` 和 `mvp/tests/`。
